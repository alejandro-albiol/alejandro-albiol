## 🧠 About Me

I build systems where clarity is the feature. Whether it's a backend API or a data pipeline feeding AI agents, I design for the person who inherits the code six months from now.

Currently, I operate at the intersection of **data engineering** and **backend development** in an industrial manufacturing environment. I design modular documentation pipelines that power AI agents, maintain production SQL Server architectures, and apply clean architecture principles to data systems that need to survive the long term.

I care about:
- Clear architecture (code *and* data)
- Separation of concerns
- Well-defined APIs & data contracts
- Maintainability over hype
- Systems that don't break when the person who built them is on vacation
